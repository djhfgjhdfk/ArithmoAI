# ArithmoAI – AI Mathematics Learning Website

## About the Project

ArithmoAI is a website that helps students learn and practise mathematics. It uses artificial intelligence (AI) to create new math problems. Students can choose a topic and a difficulty level.

## Main Features

- **AI Task Generation:** Gemini AI creates new math problems.
- **Three Difficulty Levels:** Students can choose Foundation, Standard, or Advanced.
- **Two Math Topics:** Arithmetic Progression and Area of a Triangle.
- **Check Answer:** Students can check if their answers are correct.
- **Hints:** Students can get hints when they need help.
- **Step-by-Step Solutions:** The website explains how to solve a problem.
- **Backup Task Generation:** If AI is not available, the website can still create math problems.

## Technologies Used

- **HTML** – creates the structure of the website.
- **CSS** – makes the website look better.
- **JavaScript** – makes the website interactive.
- **Gemini API** – generates math problems using AI.
- **Cloudflare Workers** – connects the website to Gemini and keeps the API key safe.

## How to Use the Website

1. Open the ArithmoAI website.
2. Choose a math topic.
3. Select a difficulty level.
4. Click **Generate New Task**.
5. Solve the problem and enter your answer.
6. Click **Check Answer** to check your result.
7. Use **Show Hint** or **Show Solution** if you need help.

## Project Goal

The goal of this project is to make mathematics practice easier and more interesting. Students can work at their own level and learn at their own pace.

## Security

The Gemini API key is stored in Cloudflare Workers as a secret. It is not included in the public HTML code.
